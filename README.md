# decision-cards · 决策卡

让 AI 在需要你做决定时，把每件事写成一张单独就能看懂、能直接回答的「决策卡」。

适合这样的人：AI 的回复一长就读不下去；常常要翻回去找「它到底在问我什么」；注意力容易被打断，或者有 ADHD。

## 它改变了什么

没有它时，AI 常这样问你：

> 我看了下部署的几种方式，A 和 B 各有优劣（见上面第三节），另外之前说的缓存策略和日志级别也还没定。你看怎么处理？

有了它：

> **决策卡 1：新版本今晚上线，还是等周一？**
> - 背景：新版本改了支付页面，测试都通过了。今晚是周五，出问题的话周末没人值班。
> - 选项 A：今晚上线。用户周末就能用上；出问题要等周一才有人处理。
> - 选项 B：周一上午上线。晚三天；出问题当场能处理。
> - 推荐：B。支付页面出错的代价，比晚三天大。
> - 怎么回：回「1 是」就是周一上线；回「1 A」就是今晚上线。
>
> 缓存策略和日志级别我按常用的默认值定了：缓存 5 分钟，日志只记错误。要改的话告诉我。

它让 AI 做四件事：

1. 先筛：自己查得到、能定的事不问你，定完告诉你。
2. 每件要你定的事写成一张卡，固定五项：问题、背景、选项、推荐、怎么回。
3. 一次最多三张，放在回复开头，带编号，可以分开回答。
4. 以前问过你、你还没回的事，重新写成完整的卡。

## 怎么用

**支持 skill 的工具（例如 Claude Code）**

把这个仓库放进工具的 skills 目录。以 Claude Code 为例：

```bash
git clone https://github.com/oaooao/decision-cards ~/.claude/skills/decision-cards
```

之后不用做别的，AI 需要你做决定时会自己用上它。

**不支持 skill 的工具（各种 AI 网页端和 App）**

打开 [paste-version.md](./paste-version.md)，把里面那段话复制到工具的「自定义指令」「个性化设置」或「项目说明」里。
